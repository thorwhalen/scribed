scribed.textgrid

scribed.textgrid¶

Praat TextGrid interval tiers, in and out: the one home for the format.

A TextGrid holds named interval tiers: {name: [(start, end, label), ...]} in seconds. read_tiers() reads them from the long or the short text form (point tiers are skipped); write_tiers() writes the long form, padding the gaps with empty intervals (Praat requires a tier to cover its whole span); trim_overlaps() makes intervals that overlap (speakers talking over each other) writable. What to do with tiers (which one holds the words, speaker prefixes, phone tiers) is the caller’s business: scribed.readers turns them into a transcript, and Transcript.as_textgrid writes one.

The tier conventions the fleet’s readers share live here too, so they cannot drift apart: which tier names hold lines, words and phones (LINE_TIERS, WORD_TIERS, PHONE_TIERS), MFA’s "<speaker> - <tier>" names (speaker_and_tier()), the tier that names each line’s speaker (SPEAKER_TIERS), and which labels are speech rather than silence or a marker (is_speech()).

>>> grid = write_tiers({"take": [(0.5, 1.2, 'say "hi"')]}, xmax=2.0)
>>> read_tiers(grid)
{'take': [(0.0, 0.5, ''), (0.5, 1.2, 'say "hi"'), (1.2, 2.0, '')]}

scribed.textgrid.is_speech(label)[source]¶

Whether an interval label is speech, not silence (SILENCE_LABELS, any case) or a marker (wrapped in MARKER_BRACKETS).

A label made only of bracket characters (a lone +, <>) is a marker too.

>>> [is_speech(x) for x in ("hello", "SIL", "spn", "<p:>", "+breath+", "[noise]", "AH0", "+")]

scribed.textgrid.speaker_and_tier(name)[source]¶

MFA’s "<speaker> - words" -> ("<speaker>", "words"). Only a known tier name after the separator (KNOWN_TIERS, any case) makes a speaker; any other name -> (None, name).

>>> speaker_and_tier("carl - words"), speaker_and_tier("notes - draft")
(('carl', 'words'), (None, 'notes - draft'))
Return type:

Tuple[Optional[str], str]

scribed.textgrid.tier_named(tiers, names)[source]¶

The name of the tier in tiers called one of names (any case, a speaker’s prefix aside), by the order of names; None if there is none.

scribed.textgrid.trim_overlaps(intervals)[source]¶

intervals sorted, each ending no later than the next begins.

For speakers talking over each other, which a single tier cannot hold. An interval that is trimmed to nothing (it starts where another starts) is dropped (of two intervals with the same start, the later-sorting one is kept).

>>> trim_overlaps([(1, 3, "b"), (0, 2, "a")])
[(0, 1, 'a'), (1, 3, 'b')]
Return type:

List[Tuple[float, float, str]]

scribed.textgrid.write_tiers(tiers, *, xmax)[source]¶

A long-form TextGrid of interval tiers spanning 0..xmax.

What read_tiers() reads back, and what a forced aligner takes as a transcript of timed lines. Gaps between intervals are filled with empty ones; a " in a label or tier name is doubled. Times are rounded to TIME_DECIMALS places before they are checked. Nothing is clamped: an interval outside 0..xmax, empty, or overlapping another is a ValueError (use trim_overlaps() first where overlap is expected). The reader strips labels, so a label’s surrounding whitespace does not survive a round trip.

>>> write_tiers({"take": [(0.5, 1.2, "a"), (1.0, 1.5, "b")]}, xmax=2.0)

str
