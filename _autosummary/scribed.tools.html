scribed.tools¶

Command-line tools for scribed (dispatched via cw in __main__).

Each function here is a thin, CLI-friendly wrapper over the Python API; cw turns their signatures into subcommands and options. Run scribed <command> --help (after pip install 'scribed[cli]') or python -m scribed <command>.

scribed.tools.find(*, local=False, remote=False, free=False, implemented=False, diarization=False, streaming=False, word_timestamps=False, language=None)[source]¶

Filter the ledger and print matching backends (id, where, pricing, best-for).

Flags compose (AND). Example: scribed find --local --free --diarization.

Parameters:

  • local (bool) – Keep only backends that run locally.

  • remote (bool) – Keep only hosted/remote backends.

  • free (bool) – Keep only free / open-source backends.

  • implemented (bool) – Keep only backends scribed can run today.

  • diarization (bool) – Keep only backends that label speakers.

  • streaming (bool) – Keep only backends that support real-time streaming.

  • word_timestamps (bool) – Keep only backends that emit word-level timestamps.

  • language (Optional[str]) – Keep only backends whose languages mention this name/code.

scribed.tools.install(backend_id, *, gpu=False, yes=False)[source]¶

Plan (default) or run (--yes) the pip install for a backend.

Without --yes it prints the plan and changes nothing. System deps and GPU wheels are surfaced, not run automatically.

Parameters:

  • backend_id (str) – Backend id to install, e.g. faster-whisper.

  • gpu (bool) – Surface GPU-wheel guidance.

  • yes (bool) – Actually run pip install (otherwise just print the plan).

scribed.tools.status(*, level='all', run_tests=False, names=False)[source]¶

Print an ASR-backend readiness table (levels: all ⊇ implemented ⊇ set_up ⊇ tested).

Parameters:

  • level (str) – Restrict rows to a level: all | implemented | set_up | tested.

  • run_tests (bool) – Actually transcription-test the set-up backends — makes real API calls for set-up remotes (off by default, so a plain scribed status never bills you).

  • names (bool) – Also print, per level, a comma-separated Name (website) list.

scribed.tools.transcribe(audio, *, backend=None, language=None, diarize=False, output='text')[source]¶

Transcribe an audio file/URL and print the result.

Parameters:

  • audio (str) – Path or http(s) URL to the audio.

  • backend (Optional[str]) – Backend id (default: first installed). See scribed backends.

  • language (Optional[str]) – Language code hint, e.g. en (omit to auto-detect).

  • diarize (bool) – Ask the backend to label speakers (if it supports it).

  • output (str) – text (default), json (text + segments), srt, or vtt.
